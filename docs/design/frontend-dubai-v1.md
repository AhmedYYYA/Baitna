# BAITNA | بيتنا — نظام التصميم الأمامي الموحد

**الإصدار:** Frontend v1 · 18 نوفمبر 2026  
**الحالة:** واجهة عرض عامة؛ لا تمثل إطلاقاً إنتاجياً أو امتثالاً أمنياً للبيانات الحقيقية.

## الهدف
توحيد الطابع البصري لمنصة بيتنا العربية/الإنجليزية عبر ستة مسارات: الصفحة الرئيسية، مساحة العمل، ملف متطلبات المالك (ORB)، دليل الاشتراطات، تجربة البناء السابقة، ولوحة الرقابة التوضيحية. تحافظ التحديثات على منطق الشيفرة الموجودة والروابط والإصدارات التجريبية.

## القرار الطباعي: Dubai بالعربية والإنجليزية
- الخط المرجعي الأول في CSS: **Dubai** للكتابتين العربية واللاتينية، بأوزان 400–700. توصية نظام تصميم حكومة دبي: https://designsystem.dubai.ae/foundations/typography
- CSS: \`--bt-font:"Dubai","Dubai Regular","Dubai Medium","IBM Plex Sans Arabic","Segoe UI",Arial,sans-serif;\`
- لا تحتوي الحزمة على ملفات \`.ttf\` أو \`.woff\` أو \`.otf\` لخط دبي. وهو خط ذو شروط ترخيص خاصة؛ استخدامه في CSS عبر خط مثبّت في الجهاز لا يُعد توزيعاً لملفه.
- **مهم:** مستخدم iPhone/iPad أو أي جهاز لا يحتوي على Dubai سيرى خطاً احتياطياً. لا يجوز الادعاء بظهور Dubai على جميع الأجهزة إلى أن يتأكد إذن صريح للتضمين الآمن عبر الويب ويتم تنفيذه واختباره. لا تنسخ الملفات من مواقع خطوط غير رسمية إلى مستودع عام.
- النصوص العربية تظهر بالعربية، مع إظهار الاختصارات التقنية بين أقواس عند الحاجة؛ واجهة الإنجليزية مستقلة. تصميم اللغة يتم عبر مفاتيح الترجمة الأصلية.

**الخطوط العامة:** عناوين واضحة؛ نصوص قابلة للقراءة؛ تباين وتفاعل مع \`:focus-visible\`؛ مراعاة \`prefers-reduced-motion\`؛ وحدات متجاوبة عند 1250/960/760/520 بكسل. لا تعيد ملفات CSS كتابة بيانات الأعمال ولا تفترض تفعيل الخدمات الرسمية.

## المواقع المطورة
1. \`index.html\` — افتتاحية معمارية داكنة، مساحة عرض غنية، بطاقات متناسقة وتدرج زمني.
2. \`demo/lifecycle.html\` — شريط تنقل متناسق، لوحات مشاريع وحقول واضحة، تقليل ازدحام.
3. \`demo/orb.html\` — استبيان متدرج، حالة الملف، مؤشرات خطوات ومراجعة المسودات.
4. \`demo/compliance.html\` — مرجعيات رسمية بمحاذاة واضحة ومناطق تحذير لا توهم بالاعتماد.
5. \`demo/index.html\` — إبقاء عرض البناء الأصلي مع هوية خطية ولونية.
6. \`demo/authority.html\` — إبقاء العرض الرقابي التوضيحي وتوحيد الخط والبطاقات.

## ملاحظة تقنية مهمة
ملف \`assets/baitna-design-system.css\` يُحمّل أخيراً في \`head\` ضمن الصفحات الست. تستخدم قواعده \`data-baitna-surface\` حتى لا تختلط الأنماط بين الصفحة التعريفية والتطبيق. لا تُحمّل منه أي فونت خارجي ولا تعيد توزيع خطوط محفوظة بحقوق.

## الاختبارات
\`node --test tests/frontend-theme.test.cjs\`

تتحقق الاختبارات من وجود الروابط والخط المعتمد والتجاوب واحتفاظ الشاشات بمعرّفات الربط. **ليست اختبارات بصرية فعلية.** قبل اعتماد التصميم نهائياً، يجب اختباره على Chrome وSafari/iPad مع خط دبي مثبتاً، والتحقق من وضع RTL/LTR والتفاف النص وحجم الأزرار عند 320 و390 و768 و1440 بكسل.

## الأمن والمنتج
- بيانات GitHub Pages تجريبية محلية فقط، وليست آمنة للبيانات الحقيقية.
- لا تغيير على الخادم الخاص أو المصادقة أو SQL أو الضوابط القانونية.
- الربط بالإنتاج يظل مشروطاً بالبوابات القانونية والأمنية المعتمدة سابقاً.
